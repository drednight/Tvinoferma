# 🎁 Твиноферма 1.1.0 — «Активация подарков»

Новый скрипт для покупки подарков за Древние монеты, исправленный календарь данжей и описание
обновления, которое теперь всегда рассказывает, что изменилось с прошлой версии.

> Обновление с 1.0.x придёт само: **Настройки → Обновления → «Проверить обновления»**.
> Данные и сессии не теряются.

---

## ✨ Главное в этом выпуске

### 🪙 Скрипт «Активация подарков»

Покупка предметов в магазине подарков за Древние монеты — сразу для нескольких аккаунтов.

- **Где найти:** меню «⚡ Скрипты» (подпись «Подарки»), кнопка «Выбрать» в списке персонажей,
  меню в трее → «Скрипты», командная палитра (`Ctrl+K`).
- **8 предметов:** Камень светлого духа, Камень асуров, Камень лагеря, Камень государя,
  Знак доблести (25 шт.), Знак единства (25 шт.), Сундук средоточия и Ключ от Книги наставлений
  (два последних — ивентовые: пока их нет на сайте, показываются заблокированными).
  Цена, наличие и описание всегда читаются с сайта при открытии окна.
- **Для каждого аккаунта** — своё количество, «цена × количество = сумма» и остаток монет;
  предметы делят один баланс. Аккаунт сайта, под которым вошло несколько персонажей, показывается один раз.
- **Фильтр и поиск:** «Все пати» / «Без пати» / конкретная пати. Аккаунты, которые могут купить хотя бы
  один предмет, стоят выше остальных; аккаунты без входа — внизу.
- **Лимиты:** «Доступно Вам: N шт.». Если запрошено больше — покупается до лимита, итог помечается
  «куплено до лимита». Лимит обновляется через месяц после последней покупки: срок запоминается,
  а при необходимости восстанавливается по «Истории монет».
- **Безопасно:** подтверждение перед покупкой, «👁 Пробный запуск», «⏹ Стоп». Одна покупка — один клик
  с проверкой названия и цены; неясный исход сверяется с балансом и «Историей монет» и не повторяется.
- **После покупок** баланс всех отмеченных аккаунтов перепроверяется и записывается их персонажам;
  «🛒 Активировать другие предметы» возвращает к выбору.
- **Журнал:** последние 300 покупок — «Настройки → Журналы», вид «Подарки».
- Проверка сайта перед покупкой показывает проценты готовности.

### 📅 Календарь данжей снова совпадает с игрой

Календарь, панель «Сегодня» и полоса недели показывали следующую категорию вместо текущей —
цикл в игре сместился на день. Теперь опорная дата — **06.10.2026, «Оружие»**:

| Дата | Данж |
| --- | --- |
| 06.10 | ⚔️ Оружие |
| 07.10 | 🛡️ Доспех |
| 08.10 | 💎 Реликвия |
| 09.10 | ⚔️ Оружие — и дальше по кругу |

Порядок прежний: Оружие → Доспех → Реликвия.

### 🔔 Тише при запуске

Журнал «Скрипты» после перезапуска больше не показывает плашками давно завершённые задачи —
они остаются только в журнале.

### 📝 Описание обновления

Окно «Доступно обновление» теперь всегда показывает изменения с прошлой версии: текст собирается
из `CHANGELOG.md` автоматически, а без описания версии релиз не собирается.
