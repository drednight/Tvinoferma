# Варианты интерфейса Твинофермы

Отдельный статический прототип: **9 экранов × 3 дизайн-направления = 27 макетов**.
Нужен, чтобы выбрать, как будет выглядеть приложение, и собрать мнение людей
до того, как переписывать настоящий интерфейс.

Прототип ничего не сохраняет, не ходит на сайт pwonline.ru и не запускает игру.
Все данные внутри вымышленные.

## Как открыть

Двойной клик по `index.html` — и всё работает. Ни сборки, ни сервера, ни сети не нужно.

Если хочется раздать ссылку (например, на GitHub Pages или внутренний хостинг),
подойдёт любой статический сервер: поднять в папке `docs/visuals` и раздать адрес.

## Как смотреть

| Что | Как |
| --- | --- |
| Сменить экран | Вкладки сверху: Сегодня, Персонажи, Пати, Марафоны, Руны, Банк, Инструменты, Профиль, Настройки |
| Сменить направление | Переключатель **A / B / C** рядом со вкладками |
| Сравнить два варианта | Кнопка **«Сравнить»** — показывает два макета рядом |
| Открыть нужный экран сразу | Ссылка вида `index.html#characters/b` — экран, направление, а с двумя буквами ещё и режим сравнения |
| Оценить | 👍 / 👎 и поле заметки под каждым макетом |

Макет всегда рисуется в окне 1440px и подгоняется под ширину экрана, поэтому
у всех, кто открывает ссылку, картинка одинаковая.

## Три направления

| | Направление | Для кого |
| --- | --- | --- |
| **A** | **Студия** — тёмная, мягкая, крупные карточки, много воздуха | Красивый скриншот, редкий аккаунт |
| **B** | **Пульт** — плотный тёмный, таблицы, моноширинные числа, всё в один экран | 50+ аккаунтов, работа за столом |
| **C** | **Светлый** — тёплый светлый фон, крупная типографика, минимум линий | Офисный день, чтение |

Разница не только в цвете: у направлений разные каркас, плотность, порядок блоков
и набор акцентов. Но функционал везде одинаковый — одни и те же кнопки, фильтры,
статусы и цифры.

## Как собрать мнение

1. Раздайте ссылку на `index.html` (или на конкретный экран, например `#characters`).
2. Каждый смотритщий жмёт 👍 / 👎 под вариантом и пишет заметку в поле под макетом.
3. Кнопка **«Оценки»** открывает сводку: по каждому экрану видно, какой вариант
   победил и почему.
4. Кнопка **«Выгрузить отчёт»** отдаёт текстовый файл, **«Скопировать отчёт»** —
   текст в буфер обмена. Отправьте его автору — это готовый разбор.

Оценки лежат в `localStorage` браузера того, кто голосовал. Своего сервера
у прототипа нет, поэтому данные никуда не уходят: их нужно забрать кнопкой
выгрузки и передать вручную.

## Файлы

```
docs/visuals/
  index.html          оболочка: вкладки, переключатель направлений, оценки
  assets/
    tokens.css        три набора токенов (цвета, радиусы, плотность, шрифты)
    ui.css            оболочка лаборатории и общие элементы макетов
    data.js           вымышленные данные: персонажи, пати, марафоны, банк, руны
    pages.js          рендер 9 экранов × 3 направления
    lab.js            переключение, сравнение, оценки, выгрузка отчёта
```

## Как перенести выбранное в настоящее приложение

Токены из `tokens.css` ложатся в `css/core/variables.css` — там уже есть такой же
слой токенов, новые значения просто заменят старые. Структура (каркас, сетка,
порядок блоков) переносится в разметку и в `js/modules/*/` — по одному файлу на экран.

Сейчас в приложении есть экспериментальный каркас `body[data-ui-style="next"]`
(`css/core/newStyle.css`). Он уже тёмный и похож на направление **A** — направления
**B** и **C** покажите людям как альтернативы, а не как замену.
