# Как оформлять большие сообщения в чатах

Поддержка зависит от приложения. Arena и многие чаты понимают часть Markdown;
Telegram/Discord/Slack отличаются. Полный набор «всех вариантов» не универсален.

## Блок как на скриншоте

Три обратные кавычки на отдельной строке, затем текст, затем ещё три.
Слово `text` — метка языка: для логов без подсветки удобно `text` или `plaintext`.
Кнопку копирования и рамку рисует сам чат, не Markdown.

````text
```text
Большой текст или журнал
Строка 2
```
````

Для кода можно указать `js`, `javascript`, `ts`, `python`, `rust`, `json`,
`bash`, `powershell`, `sql`, `html`, `css`, `yaml`, `diff`, `markdown`.
Без метки языка блок тоже работает. Набор подсветок зависит от чата.
Если внутри текста уже есть тройные кавычки, снаружи используйте четыре
(или больше, чем самая длинная внутренняя последовательность).
В CommonMark также бывают блоки с `~~~` и отступом четыре пробела, но чаты
поддерживают их не всегда. Надёжнее тройные обратные кавычки.

## Остальные формы

- Встроенный код: `` `короткий текст` ``. Если внутри есть одна обратная
  кавычка, обрамите двумя: ``` ``a`b`` ```.
- Жирный: `**важно**` → **важно**.
- Курсив: `*заметка*` → *заметка*.
- Зачёркнутый: `~~старое~~` → ~~старое~~ (расширение Markdown).
- Заголовок: `## Раздел` на новой строке.
- Цитата: `> чужой текст`; многострочная — знак `>` перед каждой строкой.
- Список: `- пункт`; нумерация: `1. пункт`.
- Чек-лист: `- [ ] проверить`, `- [x] готово` (поддержка зависит от чата).
- Ссылка: `[название](https://example.com)`.
- Разделитель: `---` на отдельной строке с пустыми строками вокруг.
- Таблица: строки `| Шаг | Результат |`, затем `|---|---|` и строки данных.
- Экранирование: `\*не курсив\*` показывает звёздочки буквально.

## Сворачиваемый блок

GitHub и некоторые Markdown-редакторы поддерживают HTML details:

```html
<details>
<summary>Показать большой журнал</summary>

Текст или блок кода здесь.

</details>
```

В Arena и других чатах HTML может очищаться или показываться буквально;
сворачивание не гарантируется. Надёжная альтернатива — вложение `.txt`/`.md`.
Спойлер `||текст||` работает, например, в Discord, но не является стандартным
Markdown. Специальные callout-блоки `> [!NOTE]` — расширение отдельных сервисов,
а не общая форма для всех чатов. Формулы `$...$`/`$$...$$` тоже зависят от чата.

## Как отправлять длинные логи

Укажите цель, затем окружение, действия и ожидаемый/фактический результат.
Прикладывайте `.txt` или `.md`, если журнал длинный; либо делите на «Часть 1/3».
Не посылайте тысячи строк скриншотами: текст можно искать и копировать.
Блок кода НЕ скрывает секреты. Перед отправкой уберите пароли, cookies, токены,
полные ссылки авторизации, почту и другие личные данные.
