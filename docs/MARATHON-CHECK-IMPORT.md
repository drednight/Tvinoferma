# Импорт марафона со страницы сверки

В настройках → «Окно браузера персонажа»:

- «Марафоны: при разборе новости читать задания со связанной страницы сверки отметок» включено по умолчанию. Читаются ссылки на supermarathon*.php на pwonline.ru и дополнительные страницы, ранее добавленные в мастере. Если найдены разные ссылки, автоматический выбор не делается.
- «Импорт марафона из сохранённой страницы сверки или новости» читает HTML/HTM до 5 МБ, включая Windows-1251. Скрипты сохранённой страницы не запускаются.

Импорт страницы сверки берёт названия, описания и цели из `.season_marathon`, общие сроки и описание правил из `.status_legend`. Не импортирует личные отметки/аккаунты. Если в файле нет канонического адреса страницы, URL не угадывается — для дальнейшей сверки его нужно указать в мастере. Если год в сроках не указан, используется текущий год с предупреждением.

В примере «Покоритель Цзинсюаня» распознаются 4 сюжетные цепочки с целью 1 и общие сроки 11 ноября — 6 декабря. В новости нет привычной таблицы заданий: при разрешённом переходе берутся задания со связанной страницы сверки. Сохраняется текст новости/правил; награды, не распознанные как структурированные пороги, не превращаются в монеты автоматически.

Создание открывает предварительный просмотр в мастере. Марафон не сохраняется без подтверждения пользователя. Для живой страницы может потребоваться авторизованный профиль; при ошибке можно импортировать сохранённую страницу сверки отдельно. HTTP-переход новости непосредственно на страницу сверки также распознаётся. Произвольные JavaScript-редиректы из сохранённого файла не исполняются.

# Проверка и слияние дублей

Поиск сравнивает только основную почту/логин и ник. Счётчик показывает пары-кандидаты и количество уникальных персонажей, не число автоматически подтверждённых дублей.

При открытии профиля список проверки временно снимается с экрана, а после закрытия профиля возвращается с прежним выбором основной карточки. При слиянии:

- вложенные непересекающиеся данные и одинаковые значения объединяются;
- различающиеся поля требуют явного выбора источника (значения контактов/паролей в диалоге не показываются);
- общая принадлежность одному марафону больше не считается конфликтом сама по себе;
- разные значения одного и того же прогресса не складываются и не перезаписываются;
- перед применением создаётся резервная копия; отказ/отмена выбора не меняет карточки;
- ограничения на хранилище ОС и сохранённые привязки удаляемой карточки оставлены: автоматическая межхранилищная миграция здесь не реализована. Изменение этих ограничений без отдельной процедуры могло бы потерять контакты.

Предупреждения можно закрыть крестиком; предупреждение об отказе слияния автоматически исчезает через 8 секунд. В мастере E добавлена существующая клавиатура-помощник: она редактирует текущую строку последовательности и не отправляет ввод в игру.
