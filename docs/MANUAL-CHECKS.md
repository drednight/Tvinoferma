# Что проверить вручную после установки

Список того, что **нельзя** проверить в автоматических тестах и headless-браузере: работа
установщика, поиск Windows, системные уведомления и окна игры. Проверять по порядку —
сначала то, без чего остальное не имеет смысла.

Версия в файлах сейчас `1.0.0`; перед выпуском поднять до `1.1.0` (см. «Перед проверкой»).

---

## Перед проверкой

```powershell
npm run check                      # lint + типы + тесты JS (сейчас 1249)
cd src-tauri; cargo test           # тесты Rust (сейчас 98)
npm run tauri build                # установщики .msi и -setup.exe
```

Установщики появятся в `src-tauri/target/release/bundle/`.

**Важно:** установленных копий сейчас нет — предыдущие версии удалены. Значит, проверка
обновления поверх старой версии возможна только из релиза 1.0.0: установите его, затем
ставьте новую и смотрите, заменилась ли она, а не встала рядом.

---

## 1. Установка заменяет версию, а не ставит вторую копию

**Зачем:** раньше `upgradeCode` выводился из `productName`, и после смены названия Windows
считал это другим приложением. Так появились **две** установленные копии: «Твиноферма» 0.2.0
и «Tvinoferma» 0.2.2 в разных папках. Сейчас `upgradeCode` зафиксирован явно.

1. Установите релиз 1.0.0 (или текущую сборку), запомните папку установки.
2. Соберите новую версию и установите поверх.
3. **Ожидаемо:** в «Программах и компонентах» **одна** запись, папка та же.
   **Плохо:** две записи или две папки в `C:\Program Files`.

## 2. Ярлык называется «Твиноферма»

**Зачем:** установщик называет ярлык по `productName` (`Tvinoferma`), поэтому поиск по-русски
ничего не находил. Ярлык переименовывается при первом запуске приложения.

1. После установки запустите приложение (ярлык пока может называться «Tvinoferma»).
2. Закройте и проверьте меню «Пуск» и `%ProgramData%\Microsoft\Windows\Start Menu\Programs`.
3. **Ожидаемо:** ярлык «Твиноферма.lnk», лишнего «Tvinoferma.lnk» нет.
   **Плохо:** остался только латинский — значит, не хватило прав; проверьте, что приложение
   запускалось (в консоли будет строка `[SHORTCUT]`).

## 3. Поиск Windows находит по обоим написаниям

Наберите в поиске Windows по очереди:

| Запрос | Ожидаемо |
| --- | --- |
| `Твиноферма` | приложение в результатах |
| `Tvinoferma` | приложение в результатах |
| `твино` | приложение в результатах |

**Зачем:** `DisplayName` теперь «Твиноферма (Tvinoferma)» и регистрируется **при запуске**,
а не при первом уведомлении. До первого запуска новой версии поиск по-прежнему не найдёт —
это ожидаемо.

**Если не находит:** Windows Search индексирует не мгновенно. Подождите и перезапустите
проводник, затем проверьте ещё раз. Убедитесь, что приложение хотя бы раз запускалось.

## 4. Уведомления Windows действительно приходят

**Зачем:** раньше приложение не было зарегистрировано как источник уведомлений, и показ
молча отбрасывался.

1. **Настройки → Уведомления → «🔔 Проверить сейчас»**.
2. **Ожидаемо:** всплывающее уведомление Windows; в подписи под кнопкой — «✅ Уведомления
   доступны».
   **Плохо:** подпись с причиной (приложение не зарегистрировано, выключены уведомления,
   включён «Не беспокоить»).
3. Проверьте, что приложение появилось в **Параметры → Система → Уведомления**.
4. Если сейчас идёт ивент (см. таблицу в README) — дождитесь напоминания: за 5/10/15/30 минут
   или час до начала, по московскому времени.

## 5. Значок окна игры в панели задач

**Зачем:** это была отдельная ошибка — значок не менялся для окон, запущенных **не** из
Твинофермы. Причина: пиксели значка отдавались декодеру файлов изображений.

1. Запустите игру вручную (не из приложения), войдите в мир.
2. В приложении: FAB → **«Запущенные окна игры»** → **«✏️ Вид…»** у нужного окна.
3. Выберите класс и примените.
4. **Ожидаемо:** название «Ник — Класс» **и** значок класса — в заголовке окна и на панели задач.
   **Плохо:** меняется только название → значок не встал.
5. Там же отметьте «Вернуть значок файла игры» и убедитесь, что значок **вернулся к игровому**
   (раньше это действие не делало ничего).

## 6. Календарь в самом приложении

Проверено в браузере, но в окне Tauri стоит глянуть глазами:

- **Вид «Неделя»** (по умолчанию): 7 колонок, время `00:00–24:00` сверху вниз, **без прокрутки**.
- **Марафон** — одна сплошная полоса через все свои дни, чуть выше остальных полос.
- **Линия «сейчас»** — красная, только в сегодняшней колонке.
- **Переключатель «Неделя | Месяц»**: месяц выглядит как раньше (с метками часов 00/06/12/18
  и легендой полосок); выбор сохраняется после перезапуска.
- Клик по шапке колонки или по записи открывает окно дня с полной шкалой.

**На узком окне** (около 1024 px) колонки не должны сжиматься в кашу.

## 7. Приветственное окно

Проверяется на пустом состоянии: удалите данные или запустите на чистой установке.

1. Запустите приложение без персонажей.
2. **Ожидаемо:** окно «Добро пожаловать в Твиноферму» с тремя карточками в ряд.
3. Нажмите **«Начать»** — окно закрывается.
4. Перезапустите приложение — **само окно больше не появляется**.
5. Кнопка **«💡 С чего начать»** над сеткой персонажей открывает его снова.
6. Кнопка **«Как это работает»** в шаге 3 показывает справку по входу на сайт.

## 8. Что уже проверено автоматически

Чтобы не перепроверять руками:

- **JS 1249 тестов**, **Rust 98 тестов**, lint и типы — чистые (в обоих часовых поясах).
- Раскладка недели, сплошные полосы марафона, дорожки наложений — тесты + замер на живом DOM.
- Отсутствие прокрутки недели — замер `overflow-y` и `scrollHeight` в реальном браузере.
- Приветственное окно: показ один раз, закрытие, повторный вызов — замер в реальном браузере.
- `upgradeCode` совпадает с прежним: `5dbcc9ea-3fb8-5bc2-bef0-11e504fb947e`.

## Порядок, если что-то не сработало

1. **Ярлык не переименовался** — запустите приложение и посмотрите консоль на `[SHORTCUT]`.
   Проверьте права на `%ProgramData%\Microsoft\Windows\Start Menu\Programs`.
2. **Поиск не находит** — запускалось ли приложение после установки; проверьте
   `HKCU\Software\Classes\AppUserModelId\com.tvinoferma.desktop` → `DisplayName`.
3. **Уведомления не приходят** — нажмите «Проверить сейчас»: приложение само скажет причину.
4. **Значок не меняется** — проверьте, не запущена ли игра от администратора (тогда нужны
   права и для приложения).
5. **Две копии приложения** — сообщите: значит, `upgradeCode` всё ещё не сработал;
   удалите лишнюю вручную и напишите, какая версия осталась.
