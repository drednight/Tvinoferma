## 5. Проверка входа не чаще, чем нужно

Если персонаж проверялся недавно, автопроверку входа для него не запускать.

Главное требование: **сама проверка должна идти по отмеченному времени** — то есть решение
«проверять или пропустить» принимается внутри самой проверки, по времени последней
отметки, а не только на стороне планировщика.

Открытый вопрос: величина интервала «недавно» и где хранить время последней проверки.
Поле `lastLoginCheck` в персонаже уже есть — скорее всего, хватит его плюс настройки.

**Статус: сделано 09.10.2026, ждёт коммита.** Отдельная настройка «Скрипты → 🔐 Автопроверка
входа» (часы, по умолчанию 6, 0 — только вручную), а не порог устаревания данных: у
подсветки «3 ч назад» в профиле и у вопроса «когда открывать окна» разный смысл. Интервал
применяется ко всем, включая тех, у кого входа нет — раньше такие выпадали из автопроверки
навсегда. Ручные пути (кнопка в карточке и профиле, «Проверить всех», проверка после
закрытия окна авторизации) интервал не смотрят. В статусе входа видно, когда следующая
проверка: «Онлайн · проверено 02.10.2026 18:20 · автопроверка через 4 ч». Фоновая проверка
из трея не запускает задачу, если интервал ещё не вышел.
