# Контакты, выбор предметов и сроки куки: проверка Windows

Это план ручной приёмки, **не подтверждение работы на настоящем пользовательском ПК**.
Автотесты используют синтетические контакты и ответы сайта. Выпуск не создаётся.

## Разные контакты в файле и Windows

1. На отдельной тестовой учётной записи Windows сохранить различающиеся синтетические
   контакты в файле и защищённой записи. Закрыть другие копии приложения.
2. Запустить приложение: сохранение остановлено, в баннере есть «Сравнить контакты и
   выбрать источник». Автоматического выбора, удаления или перезаписи нет.
3. Проверить свёрнутый список отличающихся персонажей и полей в баннере.
   Открыть сравнение: значения скрыты, отличаются выделенные строки. Показать значения
   отдельной галочкой. Проверить активных и архивных персонажей, включая намеренно пустое поле.
4. Отмена ничего не меняет. Без отдельного подтверждения кнопка применения недоступна.
5. Выбрать Windows только если именно эта версия нужна. Приложение повторно сверяет файл и
   прочитанные записи, создаёт проверенную точную копию исходного файла и заменяет только
   конфликтующие открытые контакты ссылкой на Windows. Включается защищённое хранение.
   Остальные данные, ID, очереди, ключи шифрования и привязки дисков сохраняются.
6. Проверить копию `state.backup-pre-contacts-windows-choice-*.json`. Она сохраняет старые
   контакты из файла и **может содержать пароли**: не публиковать и хранить безопасно.
   Это не копия защищённого хранилища Windows.
7. До повторной загрузки обычное сохранение заблокировано. Нажать «Перезапустить», сверить
   выбранные контакты, затем сохранить и повторно запустить приложение.
8. Изменение файла/записи во время выбора, отказ копирования или потерянный ответ команды
   должны остановить операцию без автоматического повтора. При неизвестном результате
   проверять файл и копию: ошибка не доказывает, что замены файла не было.

Записи Windows этот путь **никогда не записывает и не удаляет**. Если нужна версия из файла,
отменить выбор: её применение поверх Windows здесь намеренно не реализовано — для этого
нужна отдельная безопасная копия прежних защищённых контактов. Межпроцессной транзакции между
файлом и Windows нет; проверки не заменяют закрытие других копий приложения.

## Передача и сундуки

- В свежем «Что будет передано» пять одинаковых наборов ×50 занимают одну строку.
  Выбор 100 шт. означает два реальных набора, не разделение одного набора.
  Остальные три остаются на сайте. Иное количество внутри набора — отдельная строка; разные категории и сроки объединены.
  При выборе части берутся ближайшие известные сроки, затем неизвестные. Проверить кнопку
  «Все», общие «Поставить всё» / «Снять всё», поиск без изменения выбора. Детализация раскрывается только при разных сроках.
- Сервер для всех применяется также неотмеченным персонажам. Если нет подтверждённого
  получателя на выбранном сервере, такой персонаж не передаёт предметы и не переключается на другой сервер.
- Проверить 0, допустимый максимум, дробное, отрицательное, пустое и превышающее максимум
  значения. Некорректное количество блокирует отправку до исправления/повторной проверки.
- После изменения сайта между просмотром и отправкой прежний выбор должен быть отклонён.
- В начальном плане караванщика — персонаж и сундуки. До чтения сайта показано «Не проверено»,
  а не ноль; тот же план сохраняется при подсчёте, открытии и результате, ячейки обновляются на месте. Инвентарь общий на аккаунт.
- Пустая корзина распознаётся по сохранённым заголовку и тексту сайта; неизвестная страница не считается нулём.
  После подсчёта справа в той же таблице — количество для открытия и кнопка «Открыть найденные сундуки»
  внизу. При нуле реального запуска нет; один общий аккаунт открывается один раз.
- Карточка промокода: название, новость, срок, сервер, свёрнутый список содержимого;
  действия 🌐 → растянутая «Добавить промокод» → скрытие. Под сроком — дни включительно по Москве либо истёкший срок.
  Истёкшие скрываются автоматически; «Вернуть скрытые промокоды» оставляет их видимыми,
  в том числе после перезапуска, пока не поменялся срок. Ручное скрытие сохраняется.
  Если надёжной полной даты нет, год не угадывается: нет сообщения об отсутствующем годе,
  точный отсчёт и автоматическое скрытие не применяются.

## Активация подарков

- Слева «Обновить цены и балансы» читает все аккаунты, включая доступные лимиты.
- Над таблицей «Обновить цены и баланс» читает только отмеченных персонажей; без выбора
  предлагает отметить их, а не запускает всех. Представитель общего аккаунта берётся из отметок.
  Баланс и лимиты общие для членов того же аккаунта; чужие результаты проверки сохраняются.
- Во всех планах, результатах и подробных отчётах перед ником — класс персонажа.

## Банк куки

- Интерфейс временно скрыт у всех; при открытии настроек метаданные банка не запрашиваются.
- Хранилище куки, ключи, сроки и привязки не удаляются и не сбрасываются.
