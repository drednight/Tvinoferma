## #91 — [7.13] Запуск игры из приложения: окна, пати, трей

[Исходная карточка](https://github.com/drednight/Tvinoferma/issues/91)

Запуск окон игры (VK Play GameCenter) прямо из приложения: персонаж, несколько выбранных, пати целиком, а также из меню трея. Основа — `launcher.rs` (запуск `GameCenter.exe`, подтверждение окна «Клиент игры уже запущен», ожидание нового `elementclient_64.exe`) и `js/modules/launcher/`. Токен входа не попадает в `state.json` и в интерфейс.
- [x] Путь к GameCenter у каждого персонажа (карточка → «🎮 Запуск игры»); запуск по очереди с «Отменой», ход виден в доке задач и в журнале «Скрипты»
- [x] Вход аккаунта: «🔑 Запомнить текущий вход GameCenter» — токен в хранилище ОС, перед запуском подставляется в `GameCenter.ini` (копия исходного файла сохраняется); один GameCenter может обслуживать несколько аккаунтов
- [x] Запуск: «▶ Играть» в профиле и **на маленькой карточке** (компактные кнопки ▶ и 🌐 с подсказками), «▶ Запустить» в панели выбранных, «▶ Запустить пати» на вкладке «Пати»

- [x] Меню трея «🎮 Запустить пати»: список пати, где есть персонажи с путём к GameCenter; обновляется при каждом сохранении

- [ ] Выбор GameCenter прямо при запуске пати (список рядом с «▶ Запустить пати» и в меню трея)
- [x] Окно клиента переименовывается («Ник — Класс») и получает значок класса (`public/assets/icons/classes`): подпись и значок ставятся в фоне после появления окна; отключается в «Настройки → Запуск игры»

## #88 — Передача предметов: ограничение по времени («Награды можно будет перевести после ЧЧ:ММ ДД.ММ.ГГГГ»)

[Исходная карточка](https://github.com/drednight/Tvinoferma/issues/88)

Часть #26 (4.2 «Передача предметов в игру»).

Сайт иногда не даёт передать награды до определённого времени, например:
«Награды можно будет перевести после 20:00 10.04.2026».
Сейчас приложение такие случаи не распознаёт: заблокированная строка учитывается как «заблокировано», а ответ-предупреждение после попытки передачи показывается как «Не распознано» с текстом сайта.

Нужно:
- [ ] Получить настоящие страницы (форма с такой строкой и ответ сайта после попытки передачи), обезличить, добавить в `tests/fixtures/`.
- [ ] Распознавать «после ЧЧ:ММ ДД.ММ.ГГГГ» (время московское) — селектор/регэксп в `selectors.json`, не в коде.
- [ ] Запоминать акцию вместе со временем разблокировки (локально, рядом с `tf_transfer_limits_v1`); после этого времени ограничение снимается само.
- [ ] До этого времени не отмечать предметы акции и показывать «⏳ доступно после 20:00 10.04.2026» в «Что будет передано» и в итоге.
- [ ] Галочка «Обойти ограничения приложения» по-прежнему позволяет попробовать; ограничения самого сайта не обходятся (заблокированные строки не трогаем).
- [ ] Статус `too_early` в итоговой таблице и журнале; тесты скрипта и логики.

Готово, когда: приложение само пропускает такие акции до указанного времени, а после него отмечает их без ручного сброса.
