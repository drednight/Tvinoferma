# Уточнение «Сегодня», подарков и сравнения — 2026-11-03

Это уточнение заменяет описание opt-in и текстов новостей в предыдущем
`FOLLOWUP-AFTER-TODAY-REFERENCE-2026-11-03.md`. Релиз не выпускается.

## Изменения

- В приложении осталась только новая страница «Сегодня» без переключателя
  прежнего вида, демонстрационного вступления и нижних «Подключений».
  Каталог 80 classic / 100 next, default 07 и Atlas 07–11 сохранён.
- Новости: три последних заголовка со ссылками, без загрузки/вывода текстов статей.
  Запуск и настроенный интервал статуса серверов используют прежний публичный
  reader. Отдельная малая кнопка обновляет только новости, а не аккаунты/серверы.
- Рядом с «Открыть промокоды» — малая кнопка принудительной проверки действующих
  кодов через существующий discovery новостей. Прежнее пояснение удалено.
- Если активного марафона нет, доступен переход в раздел марафонов.
- Календарь: подписи дней недели, названия данжей вместо иконок проходок,
  возвращение к текущей дате и «Закрыть» справа внизу. Отметки дел и цикл
  «Ожидает → В работе → Выполнено» используют штатные записи planner,
  включая повторы с отдельными отметками по датам.
- «Запущено окон»; финансы берутся из того же `currentBalances`, что верхняя
  панель Банка: учтены ручные поправки переноса по месяцам.
- Подарки: баланс после ника и перед предметами, выбор предмета сразу для всех
  видимых персонажей; подписи общего аккаунта убраны, но общий кошелёк и квота
  по-прежнему считаются один раз. Offline-выбор не разрешает покупку без входа.
- Окно количеств: заголовок «Количество подарков», колонка «Персонажи», иконки
  классов, минимальная ширина ника 220 px, более ясные заголовки и «Максимум»
  отдельно по предметам. Максимум не включает невыбранные/недоступные ячейки,
  учитывает остальные предметы, общий баланс и известные квоты. Нажатие не покупает.
- Дата проверки монет автоматически выбирается по последнему моменту времени
  (с учётом часового пояса). Пустая/невалидная дата не вытесняет валидную.
  Это не выбор баланса и не разрешение переноса других полей. Правило действует
  после безопасного сопоставления в обновлении персонажей, выборочном применении
  публичных записей, полной замене и трёхстороннем объединении. Исходный аутентифицированный снимок неизменен;
  проверки идентичности, backup, roundtrip и приватной части сохранены.
- Сравнение: только отличающиеся показатели, колонки «На этом ПК / В облаке»
  с названием показателя слева. Числа проходок, характеристики и небо не
  разворачиваются целиком, если изменился один показатель. Значения выводятся
  безопасным DOM-текстом, не HTML. Приватные поля не раскрываются.

## Проверки и ограничения

Добавлены регрессии для месячных финансовых поправок, независимых ручных
обновлений, массового выбора, максимума с квотами/общим балансом, split-сравнения
и последней даты при частичном/полном применении и обновлении персонажей.
Полный прогон до финальных UI-уточнений выявил устаревшие проверки прежнего Today;
они обновлены с сохранением проверки реального поведения, включая цикл статусов.
Итоговый статус полного набора и сборки Windows нужно сверять по текущему head PR.

Браузер: приложение, календарь, раскрытое split-сравнение и offline-окно количеств
проверены на 390/768/1024/1440 px, без горизонтального выхода страницы. Ник не
сжимается меньше 220 px; узкое окно прокручивает таблицу внутри диалога.
Это не реальные покупки и не проверка Windows/сайта/двух ПК.

Яндекс: причина provider-confirmed несовпадения с сохранённой привязкой не
установлена. Повторное использование прежнего OAuth client, проверка client_id,
psuid и принудительный выбор аккаунта уже были реализованы. Подмена psuid,
сброс привязки/ключей/vault/контактов не добавлены. Сообщение уточняет отказ и
предлагает безопасный отчёт, если выбран действительно исходный аккаунт.
Google: прежний пользовательский отказ materialization тоже не объявляется
исправленным без нового безопасного диагностического подэтапа.

Остаются реальная приёмка на Windows/сайте/двух ПК, новый безопасный отчёт по
входу Яндекса, недостающие исходные картинки и будущие сведения о событиях.
Исходный эскиз split нечитабелен; реализация не заявляется его точной копией.
