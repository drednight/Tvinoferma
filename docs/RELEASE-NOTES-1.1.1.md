# Твиноферма 1.1.1

## Понятная помощь внутри приложения

34 инструкции разделены по задачам. Выберите тему или найдите функцию через поиск:
в каждой статье есть путь к кнопке, последовательность действий, ожидаемый результат
и важные ограничения. Связанные темы помогают перейти к следующему шагу.

В гайдах скриптов теперь показаны **сами окна промокодов, передачи предметов,
активации подарков и выполнения проверки**, а не страница персонажей.
Скриншоты сделаны на вымышленных данных; изображение можно открыть и посмотреть
в масштабе 100%. Справка доступна без интернета.

## Удобные настройки

Параметры разделены на «Приложение», «Синхронизация», «Обновления»,
«Данные и безопасность» и «Справка». Опасные действия вынесены отдельно.
«Информация о системе» теперь свёрнута по умолчанию.

## Исправления нагрузки и хранения

- Закрытые и заменённые формы не оставляют обработчики Escape и подписки.
- Изменение лога обновляет нужную плашку, не пересоздавая весь док повторно.
- Фоновая проверка входа не запускает новую пачку поверх незавершённой.
- Браузерные резервные копии соблюдают лимит; прежние копии не удаляются при ошибке создания новой.
- По умолчанию в журналах показан текущий сеанс; предыдущую историю можно включить отдельно.

Сессии сайта и профили WebView не удаляются автоматически. Их кэш может расти;
это не обещание фиксированного расхода памяти или места на диске.

## Обновления и календарь

При каждом запуске установленного приложения выполняется проверка новой версии.
Дополнительное расписание не отключает эту проверку. Установка — только по вашей кнопке.
Легенда вертикальной шкалы времени теперь находится только в недельном календаре.

## Установка

Скачайте Windows-установщик из этого релиза либо подтвердите обновление в приложении.
Для ручной установки сначала сохраните резервную копию данных.
