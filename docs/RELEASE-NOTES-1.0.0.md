# 🎉 Твиноферма 1.0.0 — первый стабильный выпуск

Первый релиз, который можно назвать готовым продуктом. С версии 0.3.0 приложение выросло
из менеджера аккаунтов в полноценный рабочий кабинет: отдельный экран «Сегодня» с календарём,
запуск игры с подписью окон, промокоды и передача предметов, свежесть данных, состояние парсеров,
единые журналы, трей и автозапуск.

> Обновление с 0.3.0 придёт само: **Настройки → Обновления → «Проверить обновления»**.
> Данные и сессии не теряются. Если у вас версия раньше 0.2.0, установите вручную файлом ниже.

---

## ✨ Главное в этом выпуске

### 📍 Экран «Сегодня» — новая главная страница

Приложение открывается не списком карточек, а ответом на вопрос «что делать сейчас?»:

- **Требуют внимания** — истёкшие сессии, отставания в марафонах, давно не проверенный баланс.
  В каждой строке кнопка действия: «Проверить вход», «Обновить баланс», «Открыть».
- **Сводка** — монеты, персонажи и кто из них авторизован, что скоро заканчивается, пати с онлайном.
- **Календарь и панель дня** — данж дня, полоса на неделю и все записи на сегодня рядом с сеткой.

### 📅 Календарь: записи по времени и постоянные ивенты

- **Неделя** — вид по умолчанию: запись стоит по времени начала, высота блока равна длительности,
  подписи оси каждые 3 часа. Марафоны и записи без времени подписаны под датой дня и не
  закрашивают колонку. Вид «Месяц» показывает названия записей.
- **Окно дня** с полной шкалой `00:00–24:00`; записи внахлёст разводятся по дорожкам.
- **Постоянные игровые ивенты** — повторяются каждую неделю, заводить их не нужно:

| Ивент | День | Время (МСК) |
| --- | --- | --- |
| Битва Династий | понедельник, пятница | 20:20 – 22:20 |
| Ритм Гильдии | среда | 19:30 – 20:00 |
| Запретное учение | среда | 20:00 – 21:30 |
| Арена Героев | четверг | 19:00 – 24:00 |

- **Данж дня** по циклу Реликвия → Оружие → Доспех, с цветом категории. Считается на любую дату.

### 🔔 Напоминания об ивентах

Для каждого ивента — своя галочка и выбор «за 5 / 10 / 15 / 30 минут / 1 час».
Проверка идёт раз в 30 секунд (раз в 30 минут не успевала предупредить «за 5 минут»),
журнал по ключу «ивент + дата» — одно напоминание не приходит дважды.

### 🎮 Запуск игры

- **Очередь запуска** перетаскиванием, порядок сохраняется.
- **«Запущенные окна игры»** — ник, класс, PID и время работы; закрыть выбранные, окна пати или все.
- **Подпись окон:** «Ник — Класс» и значок класса. Если автоматически не сработало —
  кнопка «✏️ Вид…» в списке окон: своё название и любой класс для значка.

### ⚡ Промокоды и передача предметов

- Активация промокодов по кнопке: несколько кодов за раз, журнал и награды, понятные причины пропуска.
- Передача предметов с чтением страницы передачи; в окне персонажа снимается лимит сайта
  «не более 6 предметов за раз» — панель «Типы предметов» с кнопками «Отметить»/«Снять».

### 🛡️ Надёжность

- **Свежесть данных:** метки «3 ч назад», настраиваемые пороги, фильтр «давно не обновлялись».
- **Состояние парсеров:** плашка «Парсер устарел», когда разбор страниц перестал находить поля.
- **Единые журналы:** скрипты, промокоды и передачи — в одном разделе.
- **Заводские настройки** с обязательным предложением экспорта.
- **Резервная копия перед обновлением** приложения, перед миграцией и перед импортом данных.

### 🆕 Ещё

- **Командная палитра `Ctrl+K`** — поиск по командам, персонажам, пати и марафонам.
- **Разбор скриншота характеристик:** файл, перетаскивание или `Ctrl+V`. Перенос подсвечивает поля:
  зелёный — выше текущего, красный — ниже.
- **Трей и автозапуск с Windows**, в том числе от администратора через Планировщик заданий.
- **Статус серверов** в шапке и **проверка обновлений по расписанию**.

## 🐞 Исправлено

- **Значок окна не менялся в панели задач**, если окно запущено не из Твинофермы:
  пиксели значка отдавались декодеру файлов изображений, который на сырых данных всегда
  возвращает ошибку — название менялось, а значок молча не ставился.
- **«Вернуть значок файла игры»** ничего не делал, хотя показывал успех.
- **Уведомления Windows не приходили:** приложение не было зарегистрировано как их источник.
  Теперь регистрация выполняется самим приложением.
- **Всё время считается по московскому времени**, независимо от часового пояса компьютера.
  Раньше «сегодня», час ежедневного напоминания и сроки марафонов уезжали у тех, кто не в Москве.
- Убраны «Скрытность» и «Обнаружение», дубли «Здоровье (макс)»/«Маг. энергия (макс)»;
  добавлен «Бонус к уровню».
- Разбор значений: `96587/96587` → 96587, `155668-166963` → 166963.

## 🔒 Безопасность и приватность

- Пароли, дополнительные e-mail и телефоны — в хранилище учётных данных ОС, **не в файле данных**.
- Куки `pwonline.ru` хранятся зашифрованными (AES-256-GCM), ключ — в хранилище ОС.
- В сеть уходят только `pwonline.ru` и GitHub (обновления). Телеметрии нет.
- Фоновые скрипты только **читают** страницы: ни кликов, ни отправки форм, ни запусков по расписанию.
- В окне приложения включена политика CSP, права окна сокращены до необходимых.
