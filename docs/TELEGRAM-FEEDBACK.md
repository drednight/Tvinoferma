# Обратная связь через Telegram

Для личных сообщений без публикации личного профиля подойдёт **отдельный бот**.
Пользователь пишет боту, а его сообщения можно пересылать в закрытый чат
модераторов. Публичный чат проще запустить без отдельного обработчика, но все
участники увидят сообщения друг друга; для ошибок и диагностики это хуже.
GitHub Issues удобно оставить основным публичным списком задач.

## Что нужно для бота

1. Создайте бота через официального `@BotFather` и выберите имя вида
   `...Bot`. Сохраните токен в защищённом месте. **Не присылайте его в чат,
   не записывайте в репозиторий, JavaScript приложения или установщик.**
2. Настройте отдельный постоянно доступный обработчик (или доверенный сервис):
   он получает обновления через webhook или long polling и пересылает сообщения
   в ваш закрытый чат. Просто создать бота недостаточно: без обработчика
   сообщения не окажутся в вашем чате. Если нужен ответ пользователю, обработчик
   должен хранить соответствие переписки и отправлять ответ через Bot API.
3. Добавьте предупреждение не отправлять пароли, почту, куки и токены; не
   прикладывайте диагностику автоматически. Настройте защиту от спама,
   ограничения размера и понятное уведомление о том, кто видит сообщения.
4. Когда бот работает, впишите **только его публичную ссылку**
   `https://t.me/ИМЯ_БОТА` в `TELEGRAM_URL` файла `js/settings/feedback.js`.
   Пустая строка скрывает карточку. Для распространения нужна новая сборка.

Бот скрывает личный аккаунт автора, но не делает пользователя полностью
анонимным: Telegram и обработчик получают идентификатор отправителя и содержимое
сообщения. Прежде чем писать пользователю, он должен сам начать диалог с ботом.
При использовании стороннего сервиса заранее проверьте, кто имеет доступ к
сообщениям и сколько времени они хранятся.
