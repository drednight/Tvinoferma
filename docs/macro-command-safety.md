# Проверка и перенос команд, диагностика запусков

## Перед вводом

На странице команды доступен «План и проверка — без запуска»: получатели по сохранённым данным, клавиши, клики, повторы, вложенные команды и завершающий фокус. Ошибки настройки и предупреждения отделены от проверок живых окон Windows. В редакторе проверка обновляется при изменениях; существующие проверки исполнителя остаются обязательными. План не гарантирует наличие окон и обработку ввода игрой.

Клики выделены как потенциально расходные действия. Включение непрерывного повтора сохраняется после завершения команды и требует отдельного выключения.

## Результаты фонового сравнения

Для отдельной фоновой последовательности доступны отметки «Не проверено», «Сработало», «Не сработало», «Частично» и заметка до 600 символов. Отметка требует подтверждения наблюдения в игре. API никогда не выставляет её автоматически. Изменение физического плана обесценивает предыдущую отметку; переименование — нет. Изменение контекста пати/ПЛ, точек, профилей или других сохранённых физических планов тоже сбрасывает актуальность отметки (консервативная проверка). Сравнивайте один способ, одну клавишу и одного получателя за раз.

## Перенос, восстановление

«Импорт / экспорт» переносит команды, опционально точки и профили. Пароли, настройки входа, черновики, ручные результаты и корзина не экспортируются. Названия и локальные ID могут раскрывать пользовательские сведения — проверяйте JSON перед передачей.

По умолчанию импорт создаёт копии; замена по названию требует явного режима. Сначала показывается список изменений. Сочетания и разрешение кликов сбрасываются, включается строгий выбор получателей. Импорт заблокирован до проверки и сохранения в редакторе, в том числе во вложенной команде. Внешние ссылки на команды/точки/профили не привязываются случайно к локальным объектам. Координаты, DPI, ПЛ и локальные ID требуют проверки на другом компьютере.

Редактор сохраняет локальный черновик и предупреждает о закрытии с изменениями. При следующем открытии восстановление предлагается, но не применяется автоматически. Ошибка localStorage показывается отдельно. Последние пять удалённых команд можно вернуть; занятое сочетание при восстановлении сбрасывается. Это не резервная копия всего приложения.

## Журнал по запускам

«Диагностика по запускам» показывает и экспортирует JSON текущего сеанса: runId, конфигурационную проверку, IPC-этапы, измеренную длительность IPC, число найденных окон, запросы ввода, результат Windows, завершение/отказ и восстановление горячих клавиш. Для фоновых отчётов отдельно сохраняются доступные проверки личности/состояния/прав/физического ввода и фазы уведомлений/нажатия/отпускания/восстановления. Отсутствующие данные не считаются успешной проверкой.

До 20 запусков, до 250 событий на запуск (первые 50 и последние 200); пропуски подсчитываются. Одинаковые соседние события объединяются. Не добавлены дополнительные фоновые пробы или задержки; собираются уже полученные результаты. Поздний ответ IPC не прикрепляется к другому запуску. Журнал не переживает перезапуск. Обычный журнал и структурированная история очищаются вместе.

В JSON передаются только разрешённые поля, не полные IPC-аргументы, пути клиента или содержимое учётных записей. Перед публичной отправкой всё равно просмотрите файл: он содержит локальные ID, клавиши и этапы команды. Ошибки 1460/5, смена foreground и отказ preflight имеют разные объяснения. Таймаут не доказывает недоставку. API_OK_GAME_UNKNOWN означает только принятие запроса Windows.

## Проверка интерфейса

`npm exec vitest -- run tests/gameMacrosSafety.test.js tests/gameMacrosPanel.test.js tests/gameMacrosRuntime.test.js`

Для реального Chromium: запустите Vite и `node scripts/test-macro-browser.mjs`. Требуются `playwright-core` и Chromium; можно задать `PLAYWRIGHT_MODULE`, `CHROMIUM_EXECUTABLE`, `MACRO_TEST_URL`. Проверяются создание/настройка/сохранение/редактирование/удаление/возврат, план, защита закрытия, клавиатурное открытие/Escape и ширина 390px. Этот браузерный тест не проверяет Windows IPC и реакцию PW.

## Внешний мультибоксинг

Сторонняя программа может использовать иной способ доставки и полезна как отдельное сравнение, но сама по себе не обеспечивает ввод в неактивный PW. Перед экспериментом нужно выбрать конкретную программу, проверить её механизм и актуальные правила игры. Не устанавливать драйверы, не внедрять DLL, не обходить защиту; не запускать одновременно два повтора. Установка сторонних программ этим изменением не выполняется.
