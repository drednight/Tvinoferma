# Как добавить запись «В разработке»

В приложении раздел «Настройки → Обновления → История обновлений» собирается из
файла **`CHANGELOG.md` в корне проекта**. Карточка «🚧 В разработке» — это раздел
`## [Unreleased]` в начале файла. Он предназначен для изменений, которые ещё не
оформлены отдельным релизом; всё, что туда записано, попадёт в историю при
следующей сборке приложения или сайта.

## Добавить изменение

1. Откройте `CHANGELOG.md` и найдите `## [Unreleased]`.
2. В существующей секции, например `### Кратко`, `### Добавлено`,
   `### Улучшения` или `### Исправления`, добавьте строку с `- `:

   ```markdown
   ## [Unreleased]

   Краткое описание будущего обновления.

   ### Улучшения

   - В настройках появилась новая кнопка.
   - Исправлено отображение списка персонажей.
   ```

3. Сохраните файл и пересоберите приложение. История встроена в сборку через
   `js/desktop/changelog.js` (`CHANGELOG.md?raw`): **одного редактирования файла
   на GitHub недостаточно для уже установленной сборки**. После выпуска новой
   версии пользователи увидят обновлённую историю; сайт обновится после сборки и
   публикации GitHub Pages. Локально изменения видны через Vite.

Вступительный текст перед первой `###` показывается как описание выпуска.
Заголовки `###` отображаются внутри карточки, повторяющиеся заголовки одного
выпуска объединяются. Каждый пункт пишите **одной строкой**: текущий разборщик
берёт текст после `- ` и не объединяет последующие строки с пунктом. Разметка
Markdown внутри пункта (например, `**жирный**` или `[ссылка](адрес)`) сейчас
показывается обычным текстом, а не форматируется.

## Когда выходит версия

Добавьте под свежим `## [Unreleased]` заголовок вида
`## [2.3.0] — 2026-11-01` и перенесите в него подготовленные изменения. Оставьте
новый `## [Unreleased]` для следующей версии. Версию приложения в нужных
файлах обновляет `npm run version:bump 2.3.0`; этот скрипт **не переносит**
записи в `CHANGELOG.md` — историю нужно отредактировать отдельно. После этого
соберите и выпустите версию обычным для проекта способом.
