# Виджеты страницы «Сегодня»

В настройках откройте редактирование страницы «Сегодня», затем «Добавить виджет».
Библиотека объединяет блоки в группы и показывает неактивный предпросмотр с текущими
данными. Выберите размер, добавьте блок, переместите его за заголовок и при необходимости
растяните за угол. Изменения сохраняются только после кнопки «Сохранить»; «Отмена» их
отбрасывает. Удалённый блок можно добавить снова. «Стандартное расположение» сбрасывает
раскладку после сохранения. В режиме редактирования действия внутри карточек заблокированы.

Новые блоки по умолчанию скрыты и не меняют существующую раскладку:

- **Персонажи** — активные карточки, последнее состояние входа на сайт и баланс по
  последним сохранённым проверкам. Нет проверки — это не подтверждённый вход и не нулевой
  баланс. Дата показана по Москве; старый формат разбора баланса помечен для перепроверки.
- **Пати** — участники основной и дополнительных пати и число входов, подтверждённых при
  последней проверке. Это **не** количество запущенных игровых окон.
- **Финансы** — остатки по записям раздела «Банк», а не текущие значения из игры.
  Древние монеты намеренно не суммируются: несколько карточек могут относиться к одному
  аккаунту. Проверенные значения доступны по карточкам в виджете персонажей.
- **Ближайшие события** — события и невыполненные дела на семь календарных дней по
  Москве (включая уже прошедшие события сегодняшнего дня), расписание и начало/окончание
  марафонов; до восьми строк и переход в
  календарь для остальных. Завершённые дела не включаются.

Предпросмотр не выполняет проверки или игровые действия. Виджеты отображают сохранённые
сведения, которые могли устареть; их открытие не обновляет данные сайта. Размер и позиция
сохраняются в настройках страницы, содержимое остаётся в соответствующих разделах.
