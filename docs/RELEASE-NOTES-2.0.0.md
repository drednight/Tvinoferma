# 🎁 Твиноферма 2.0.0 — «Две колонки и история»

Крупное обновление интерфейса: профиль персонажа, настройки, марафоны и окно редактирования
перестроены в плитки и колонки, приложение начало помнить прошлые значения характеристик,
а уведомления получили выбор набора звука с прослушиванием.

> Обновление с 1.2.x придёт само: **Настройки → Обновления → «Проверить обновления»**.
> Данные и сессии не теряются, старые файлы читаются как раньше.

---

## ✨ Главное в этом выпуске

### 🧙 Профиль персонажа в две колонки + история характеристик

Профиль больше не простыня: слева то, чем пользуются каждый день, справа — характеристики.

- **Слева:** контактные данные (один глаз на все контакты сразу), настройка GameCenter,
  примечания, проходки в данжи и последние изменения характеристик.
- **Справа:** характеристики плитками — подпись сверху, значение снизу. Длинные названия
  («Показатель атаки (ПА)», «Урон по монстрам») больше не обрезаются.
- **Разница с прошлым значением:** рядом с числом появляется `+120` зелёным или `−30` красным,
  а в подсказке — прошлое значение и когда оно было.
- **История изменений:** приложение запоминает снимки значений до изменения (10 последних)
  и показывает, что, когда и на сколько поменялось. История переживает перезапуск.
- **Теги в профиле** кликабельны: открывают список персонажей с этим тегом.
- Группы характеристик перестроены: бонус к уровню и пробивание переехали в «Показатели боя»,
  группа называется просто «PvE», основные характеристики — ровно 2×2.

### ✏️ Редактор персонажа повторяет вид карточки

- Те же панели и две колонки, что в профиле; проходки — под контактными данными.
- Под каждым полем характеристики видно «было …» и разницу, которая **пересчитывается при вводе**.
- Имена полей и разбор скриншота не изменились: «Заполнить со скриншота» работает как раньше.

### 🔔 Уведомления: выбор набора звука

- Четыре набора: **Чёткий**, **Мягкий**, **Сигнал**, **Глухой** — с пояснением под списком.
- Кнопка **«🔊 Послушать»** играет выбранное, даже если звук выключен, и честно объясняет,
  если браузерный движок ещё не разрешил звук.
- Для срочных видов (марафон, ивент, запуск и ошибка) выбранный набор звучит дважды.

### ⚙️ Настройки: открыт один раздел

- Слева липкий список разделов, справа — открытый раздел целиком вместо шести подряд.
  Добраться до нужного больше не нужно прокруткой.
- Переходы по прямым ссылкам и из справочника работают: ссылка открывает нужный раздел,
  в том числе когда ведёт на панель внутри него.
- «Помощь по приложению» открыта сразу, «Горячие клавиши» переехали внутрь неё.
- Кнопка «Пройти базовый гайд» из «Справки» убрана — гайд открывается из шапки.

### 🏃 Марафоны: плитки, пять колонок, ясная страница

- Карточки списка: плитки вместо строки с эмодзи, сетка в пять колонок, выравнивание
  по нижнему краю. Папки шире карточек — 350 px.
- Страница марафона: отдельная панель шапки с действиями, плитки показателей,
  общая панель фильтров, подсветка строки таблицы «персонажи × задания».
- Задание в мастере стало карточкой из двух рядов: поля сверху, описание снизу.
- **Временно скрыто:** выбор страницы отметок и источник «Страница отметок». Код на месте,
  вернуть достаточно снять класс `tf-hidden`. Марафоны, созданные раньше, по-прежнему
  сверяются с сайтом по сохранённому адресу.

### 🧭 Док задач стал частью шапки

- Вместо отдельной «пилюли» с рамкой и скруглением — вертикальная линия-разделитель.
- Строка шапки в сетке стала по содержимому: док больше не залезает на границу содержимого.
- Выезжающий список переоформлен отдельной панелью: строки — карточки с цветной меткой статуса.

### ❔ Гайд и справочник переписаны под новый интерфейс

- Окно «Как всё работает»: шаг в две колонки — слова слева, снимок с пометками «на что смотреть»
  справа; степпер в одну прокручиваемую строку; добавлен шаг «Профиль и характеристики».
- Тексты статей приведены в соответствие с интерфейсом: наборы звука, разница характеристик,
  двухколоночная форма, инструменты в отдельном разделе, настройки в две колонки.
- Каждая статья показывает свой снимок, а не общий; все 24 снимка используются по делу.

## 💾 Данные и совместимость

- Формат `state.json` прежний: старые файлы читаются как есть, обновление ничего не теряет.
- В персонаже появилось новое поле `statsHistory` (снимки характеристик). Старые персонажи
  без него работают: история просто начнёт наполняться с первого сохранения формы.
- Контакты по-прежнему хранятся в защищённом хранилище ОС, а не в файле данных.

## ⚠️ Известные ограничения этой версии

- **Клик по всплывающему уведомлению Windows не открывает журнал.** Само уведомление
  приходит и работает; обработчик клика требует COM-активатора, который пока не реализован.
- Страница отметок скрыта в мастере (см. выше).

## 🔧 Если что-то пошло не так

1. **Настройки → Обновления → «Проверить обновления»** — проверить версию и переустановить.
2. **Настройки → Данные и безопасность → ☁️ Резервные копии → «Восстановить»** — откат к
   состоянию до обновления. Копия также создаётся автоматически перед установкой.
3. **Настройки → Справка → Помощь по приложению** — инструкции по любому разделу с поиском.
