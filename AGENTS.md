# Правила работы с репозиторием

## Обязательное форматирование

- После изменения файлов, поддерживаемых Prettier, обязательно запускать `npm run format`.
- Перед коммитом и завершением работы запускать `npm run format:check` и исправлять найденные нарушения. Это постоянный этап проверки, а не разовая задача.
- Учитывать конфигурацию Prettier и исключения репозитория; не менять их ради прохождения проверки.
- Для изменённых файлов Rust дополнительно запускать `cargo fmt --manifest-path src-tauri/Cargo.toml --check` (при необходимости сначала `cargo fmt`). Prettier не заменяет rustfmt.
- Не включать посторонние пользовательские изменения в коммит вместе с результатами своей работы.
