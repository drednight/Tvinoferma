Внешний API Твинофермы

Эта страница открыта с самого приложения: http://127.0.0.1:47831. Токен создаётся и перевыпускается в приложении: Настройки → 🔌 Внешний API. Здесь он хранится только до закрытия вкладки (sessionStorage) и в разметку не вшит.

Увидели эту страницу, но не включали API? Тогда доступ к ней на этом компьютере есть у любой программы. Выключите сервер в настройках приложения.
