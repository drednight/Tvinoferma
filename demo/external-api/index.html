Внешний API Твинофермы

Так будет выглядеть страничка, которую отдаёт сама Твиноферма по адресу http://127.0.0.1:47831/. Она нужна для двух вещей: посмотреть и потрогать данные руками и скопировать готовый запрос для своей программы.

Да, сторонняя программа сможет запускать окна. Запуск одного персонажа, пати целиком или выбранных участников идёт тем же кодом, что и кнопки в приложении (launchOne, launchPartyByName), только без диалогов. Изменение статов и проходок меняет базу Твинофермы, а не значения в игре.

1 · Подключение

Токен создаётся в приложении: «Настройки → Приложение → 🔌 Внешний API». Он показывается один раз, полностью или частями, и хранится в приложении как хеш. В макете подойдёт любой текст — кроме пустого.

сервер: не подключено 127.0.0.1:47831 права: чтение · изменение · запуск

Почему так: порт слышит только этот компьютер, но открыть его может любая программа и любая вкладка браузера. Поэтому без токена — 401, с чужим Host — 403, а CORS-заголовков нет вовсе.

2 · Панель управления

Персонажи, статы и проходки редактируются здесь же; справа — пати, запущенные окна и ход задания на запуск. Каждое действие попадает в журнал с точным запросом и ответом.

          Коды ошибок, которые важно различать
          
    
            
  • 401 unauthorized — нет токена или он не тот. Токен в приложении можно перевыпустить.
    • 
            
  • 403 forbidden_host — запрос пришёл не на 127.0.0.1/localhost.
    • 
            
  • 403 forbidden_scope — право выключено в настройках.
    • 
            
  • 404 no_such_character — персонажа с таким id нет (или он в архиве).
    • 
            
  • 423 storage_blocked — приложение в режиме «Сохранение остановлено», изменения запрещены.
    • 
            
  • 429 launch_busy — уже идёт внешний запуск; повторите позже.
    • 
            
  • 400 confirm_required — закрытие окон запрошено без confirm: true.
