Интерактивные макеты четырёх операций: настройка слева, план и ход работы справа. Проверка, обновление и запуск имитируются — демо не читает сайт, не тратит монеты и не меняет данные приложения. Названия товаров и правила планирования сверены с текущим приложением; цены и балансы в макете только для примера.

💡 Полоса у имени показывает состояние входа на сайт: зелёная — есть вход, красная — нет входа, жёлтая — проверка. Рядом — иконка класса. Это не индикатор запущенного окна игры.

вариант B

Настройка + проверка + план

«Передача» показывает пример предметов у каждого аккаунта и выбор сервера и получателя. «Подарки» показывают пример цен, баланс и расчёт количества и остатка для каждого аккаунта. «Сундук» сначала показывает найденное количество. Кнопка обновления повторяет демо-проверку.

При ручном выборе открывается окно с поиском и фильтрами; список пати виден только в режиме «По пати». Персонажи одного аккаунта сайта разделяют баланс и инвентарь.

Демо: demo/tools-modals.html, tools-modals.js, scenarios.js и scenario-fixtures.js. Запуск локально: npm run demo. Это прототип, а не релизные окна.
