Резервные копии

Перенос данных

• «Экспорт всех данных» сохраняет всё: персонажей со всеми полями (статы, проходки, монеты и история, теги, контакты), пати, марафоны, настройки.
• «Гибкий экспорт» — выбранные персонажи/пати/марафоны; можно исключить пароли и другие группы полей.
• Импорт: новые персонажи добавляются, для совпадающих (тот же ник) открывается сравнение карточек — по каждому полю выбираете, что сохранить.

📄 Логи скриптов

Логи автоматических скриптов

Проверка авторизации, обновление балансов, поиск и сверка марафонов. У каждого запуска есть подробный лог по шагам: если что-то пошло не так, откройте запись, нажмите «Скопировать лог» и отправьте разработчику. Пароли и почты в логи не попадают.
